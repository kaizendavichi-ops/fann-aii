Belum Dikonfigurasi

Isi API key dan detail provider AI kamu sendiri di sini. Data ini hanya disimpan di browser kamu (localStorage) dan dikirim langsung ke provider AI — tidak melalui server Fann AI manapun.

Tentang Fann AI

Fann AI adalah aplikasi 100% front-end (HTML, CSS, JavaScript murni) tanpa backend/database server. Seluruh data (mission, history, progress) tersimpan di localStorage browser kamu. Fitur AI memerlukan koneksi ke provider AI eksternal yang kamu konfigurasi sendiri di atas.
